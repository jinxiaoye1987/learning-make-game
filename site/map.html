职业心态

#1 做游戏不是玩游戏
做游戏是工作 收钱就是专业；不按喜好立项 终极目标让玩家开心

#7 辛苦会忘，作品会留！
玩的人越多 辛苦回报越大；辛苦会忘 作品会留 尽量不留遗憾

#8 总监要有个性
对细节敏锐 看到别人看不到的；有平衡感与表达力 总监需要个性

#9 总之，现在就做！
没干劲时马上动手；干劲随后来 成功靠出手次数

#10 我是如何坚持写专栏的
擅长输出 不花太多时间 不太在意；习惯要轻松看待 而非义务

#13 多输入，多输出
输入与输出都要粗 并养成习惯；输入因人而异 关键是反刍而非左耳进右耳出

#16 暗示的力量
想象有东西在追 比奔向目标更有效；把截止日期当成逼近的追兵

#18 竞争与丰富
商业作品必然竞争 也和过去作品竞争；竞争中彼此支撑 有人辛苦换来他人快乐

#19 说出口，就可能成真
说出的话塑造自己的姿态；把负面转成具体改进的燃料 动起来的人赢

企划与沟通

#2 演示讲究速度！
削掉赘肉 只讲必要；图要简洁 讲得密而快

#5 企划书的写法
一页一图两行字 一页一个说明项；页数无关 好懂有趣妥当 不照读

#6 企划书要趁热、要快
趁热一口气写完 删掉图表调研和 Plan B；乐趣靠打磨 传达魅力是企划者的责任

#11 不要依赖「Plan B」
企划书只写想透的唯一方案；企划是骨架 要一以贯之

#14 把内压保持在高位
写完前别说 用内压把点子压浓；别用聊天或 SNS 泄压 把劲砸进工作

#21 想不出点子的时候
先定义问题主题 有种子才有抓手；大量试错 抓住细线索深挖 数量优先

团队与决策

#3 你打算去跟玩家解释吗？
玩家只在乎好不好玩；方便优先给玩家 理想与技术取平衡

#4 规格变更
改规格要避免但需灵活 乐趣在企划阶段想清；发现问题马上说 集体智慧选最优解

#15 不要什么都靠多数表决
多数表决选出最平庸的方案；核心人物负责决定 需平衡感与充分信息

#20 回声室效应
SNS 只见赞同 会自我强化；要能客观看待 鲜明个性也有价值 最终取平衡

#23 上即是下，下即是上
领导不比员工高 实际是从下往上请求；对周围的人保持敬意 团队都是伙伴

创作与市场

#12 分岔的口味
价值观随成长分岔 树干市场最粗；选目标要俯瞰市场 不凭个人好恶

#17 坚守你的概念
概念是魅力方向的核心 像灯塔之光；中途别改方向 总监必须随时看清它

#22 千万别吵架

游戏性的定义

#1 风险与回报
游戏性 = 风险与回报；攻略 = 压低风险拿回报的方法

#2 施压与释放
先施压再释放才有快感；回报让玩家能更好地应对下一次压力

#4 游戏性之外的乐趣
游戏的乐趣不等于游戏性；7 类游戏性之外的乐趣 边界模糊

#8 真的需要敌人吗？
压力 释放 成长 进展；敌人可去掉 压力不可少

#17 游戏性越高，大众性越低
风险与回报大致成正比；按目标人群决定游戏性高低

#20 什么是「游戏（玩耍）」？
玩耍四要素：竞争 偶然 模拟 眩晕；玩耍是让人活力生活的训练与疗愈

#21 版权游戏首先要忠于原作
原作是游戏设计的束缚；最重要的是像原作 回应粉丝

#23 让「工作」类游戏变好玩
现实题材 能赚钱 默默沉迷；工作 赚钱 强化的平衡

各类型的游戏性

#3 RPG 的游戏性
探索：越深越危险也越有收获；战斗：观察、试探、攻击弱点

#11 落块解谜的游戏性
堆积 = 风险 消除 = 降低风险；先懂原理 不擅长也能快速构思

#16 射击游戏的游戏性
靠近敌人 风险高 回报大；武器一长一短 选择缺点换优点

#22 动作游戏的游戏性
每个动作都是危险与机会一体两面；跳跃 冲刺 近战 射击 回避 躲藏

#26 策略游戏的游戏性
克制关系 + 成本与特性 = 用战略压倒对手；随机略不公平 用攻击范围也能产生博弈

难度与平衡

#5 恶魔之釜
投入越多 难度越高 回报越大；失败自动降难度 但需更好的新手引导

#6 让玩家「钻空子」
攻略 = 少吃亏多得益；容许游戏内一定程度的小作弊

#13 登山不只是爬坡
强度曲线不要单调成正比；难关加回报 也要有平地

#14 让重试快一点
失误到能再操作的时间 玩家迅速冷却；失败表现短而有力 尽快交还操作权

#15 你的游戏值得一再重来吗？
重来机制需要「想看后面」的动机；别照搬高难度 按体量设计推进速度

#24 总比打不通关好
打不通关最糟 救济胜过放弃；不带屈辱感的救济 中途可改难度

#25 指定攻略与攻略平衡
固定攻略：精心但像教程；自由攻略：多样但偏粗糙 关键是定方向

#28 优点和缺点都要放大
削峰填谷会让角色趋同；保留凹凸 用其他参数调整

#29 调平衡时给自己加个让分
开发者勉强能过 = 对玩家太难；给自己加让分 难度往下调

风险与回报的设计

#7 「会坠落」才卖得出飞翔感
要表现飞翔 先加入坠落；加入一个规格时 也加入与之相反的要素

#9 先想好回报
回报是推进游戏的欲望之源；积攒的数值要和有魅力的消费成套

#18 升龙拳指令
输入过程本身就是风险递增；发生无敌 越吸引对手越有利

#27 玩家做得有多好？
按玩家做得多好来定奖惩；别做过头 偶尔大胆打破常规

对战与竞争

#10 对战游戏一定要复杂吗？
要能玩几百次 就需要相应的深度；每次开发都重审规则 不把理所当然当理所当然

#12 被打倒反而松了一口气？
被打倒也能释放压力；赢输双方都觉得有趣才是最好的娱乐

#19 排行榜的利与弊
排行榜给目标感也带来屈辱；世界战斗力：逆向排名 不显示顶层

基础概念

#1 帧率
帧 = 画面刷新的单位，通常 60fps；60fps 与 30fps 观感差很多；可变帧率 ≠ 处理落帧；PAL 50Hz 曾让游戏变成 5/6 速

#9 学会数帧！
所有动作以帧为基准；「1 和 2 和 3」≈ 每拍 30 帧；以 15/30 帧为参照估算；人的体感也能发现数据错误

开场与引导

#2 先让玩家玩起来！
最初 3 分钟要让人明白乐趣；前置铺垫少 尽早进入游戏

回报与动机

#3 让回报始终在视线内
把回报吊在眼前 明示目标；目标放在伸手可及处

开发者之路

#4 以做游戏为生
进游戏业的最短路径是自己做游戏；给人玩 看反应 改进 加入原创性

画面与表现

#5 看世界的小窗口
显示器视野仅约 30°；驾驶舱视角最真实却难玩；VR 的取舍；小标靶缺乏娱乐魄力

#15 3D 游戏的晕动
晕 = 眼睛与内耳信息的矛盾；游戏晕与晕车方向相反；玩家侧对策；开发侧：关掉步行晃动、固定框架、选项

#25 色彩更少的世界
只靠颜色区分会让色弱玩家无法游玩；用色弱滤镜（Photoshop 校样）检查；为相近颜色拉开明度；转黑白检查前后景醒目程度

操作与手感

#6 一个按钮的可能性
一键游戏四类：连打 时机 抢按 切换；别为加功能而加 简单才见演出

#20 玩家已经知道的话就容易了
已知的东西可省略说明；利用事实标准；按键设置必不可少；摇杆与十字键根本不同

发想方法

#7 分解、考察、再构建
分解 → 考察 → 再构建；卡比空中滑翔的漂移加速

#16 用分层大纲整理
分层大纲 = 用文字管理的文件夹结构；可折叠、可调换；Word：视图 → 大纲；给自己用；给人看需整理

体验设计

#8 好的跑腿与坏的跑腿
报酬与回报合适；获得喜悦的间隔要短；给予攻略自由；完成后迅速撤收；让人期待展开

#10 让教程显得自然
直接投入实战边玩边学；视觉操作指引要配合按键设置；新技能用说明文 + 小视频；教程不能像作业

#11 夸奖玩家！
大乱斗里悄悄响起的欢呼；报酬 ≠ 夸奖；《三国无双》《Forza》的褒奖；失误爆炸里混入纸屑

#12 别没有反应
菜单确定键可分配给多个按钮；按了没反应很寂寞；过场中按键可显示跳过；避免看不出是否按下的反应

#14 选边站的乐趣
观战要有支持的一方；大乱斗观战模式的小额押注；知名选手助长观战；押注规格需符合各国法规；二选一比纯随机更有好印象

#17 规划游戏的奖励
最有效的奖励：让角色变强；不是所有企划都能这样；大乱斗的各种奖励；挑战板：给游戏以目的；动机与报酬是一体两面

#21 自定义让想象力去玩
自定义过程本身要好玩；① 效果可视化；② 优缺点分明；③ 易于挑选；④ 快速试用；⑤ 外观要帅

#23 呈现分数
分数的意义变淡了；脑年龄改变了游戏的意义；游戏偏差值、被害总额；世界战斗力；别把分数当理所当然

#29 对新手温柔一点
苦涩回忆：痛扁路过的情侣；放水不是没礼貌；引入游戏世界前要降低门槛；别手把手到让人冷掉

#30 珍惜玩家给你的时间
游戏时间是成本；与一切争夺时间；游戏开始门槛高；只提供好玩的部分；重视「操作交给玩家」的时间

剧本与演出

#13 游戏剧本很特别
剧情可能碍事；基本是主角视角；主角要一直赢；同伴难以死亡/离队；先玩游戏，剧情随后

#27 游戏内过场动画
实机过场有时比预渲染更好；过场有价值也有代价；可跳到中途或快进；所有过场都必须可跳过；QTE 慎用

#28 从高潮开始
导入非常重要；许多游戏起步太慢；事件发生就从那里开始；帕尔提娜第 1 章：1 分钟内美杜莎登场；至少让序章短

企划与提案

#18 避免「像某某一样」
人需要类比才能认识；企划书阶段传达极难；企划方别说「像某某」；理由一：类似不如玩原作；理由二：尺度因世代而异

#19 做续作
照搬续作销量约减半；游戏需要先开发系统；续作在制作上有利；前作满意度影响续作；要让人觉得比前作更强

#22 做「类似」的游戏
做出来就值得称赞；「玩原作不就好了？」；要有原作没有的多项魅力；魅力是方向，不是一维比较

角色与关卡

#24 用参数让角色立起来
性能偏离中性，开拓可能；戈尔多：靠配置产生意义；特性尖到一句话能说清；特殊规格麻烦但不可避免；先凹凸，再补问题

#26 电脑控制的玩家（CP）
人类无法反应的动作很不讲理；骰子也会被怀疑；CP 靠数据决策；逻辑冲突会卡住；特别版：反射神经 + 攻击性

《Final Fight》让命中停顿深入人心；停顿 + 微振动；八项特殊规格；每一项都难以察觉，积累起来让游戏更好

操作与手感

#2 赋予按钮「重量」
同一按钮，轻重感不同；速度、惯性、跳跃、延迟、帧率都影响；手也能感受到信息；大乱斗推敲手感；每代主机重设摇杆死区

移动与物理

#3 跳跃物理
初速度 + 每帧下落加速度；X 轴大致保持速度；依游戏目的改变跳跃；同轨迹不同速度 → 手感不同；特别版：开头极强上升 + 急减速

#7 速度的单位
速度 = 距离 ÷ 时间，知二求一；像素游戏常用「点/帧」；不同主机分辨率不同，同一数值速度不同；3D 可用真实单位，也可能用 m/帧；先统一距离感与时间单位

#8 悬崖边的行为
无条件掉落：老游戏常见，要判断是否合适；移动掉、动作不掉；按动作决定掉不掉（最正统）；注意速度继承；3D：推摇杆才掉、方向补正、自动跳

镜头与画面

#5 别把注视点黏死

#6 对「慢」说不！

#17 快速的画面切换
画面切换尽量迅速；慢吞吞的淡出、长黑屏夺走玩家时间；完全没演出也会困惑；暗转常用于掩盖读取（《生化危机》开门）；《塞尔达》卷屏帮助理解位置；wipe 贴合主题且够快可用

引导与教学

#12 教玩家怎么玩

随机与平衡

#13 随机性为游戏添彩
优点：不易腻、保持新鲜感；随机反而带来应对局面的策略；缺点：不公平，运气差的失败难接受；运气参数化（Wizardry 1981）；认真比拼时随机被敬而远之；电脑只能伪随机，要参考不确定值

#14 让分系统
实力差距会残酷地拉开；落后加速、道具优待：不公平，但休闲游戏应该加；家庭里要有输有赢；《大乱斗》原则上不给落后者加强；领先者更难拿 Smash 球；人力让分最有效；还有自动让分

#15 平均就是平庸
平均 = 平庸；只看强弱，性能会被平均化；有长处就加大短处，别扼杀个性；马力欧对马力欧最平衡但无趣；不同碰撞才有丰富博弈；线上胜率：最高 51.43%、最低 47.18%

动作与表现

#18 偏移重心会怎样？

#9 当天的事当天做完

#10 别把决定往后推
原则上当场决定；有决定权的人在场就逼他决断，他应即决；判断错误浪费大量时间，但多数时候没空犹豫；等判断的案件悬在半空；判断需要准确信息；保持弹性：发现错就再判断

#13 总监与制作人
总监 = 监督：几乎掌握全部内容判断权；通常一队一人，最终决定权要明确；制作人：管理、资金、座组、宣传；计算开发费与预期收益；宣传让总监腾出时间；界线模糊：可互相兼任；总监管一款品质，制作人俯瞰全公司

#15 总监的工作是「削减」
总监 = 决定方向、做各种决策；决定不一定让用户开心；预见损失，扔掉沉重/易燃的货物，修正航线；总监自己理解并调整问题最快；完成的作品都是削减出来的；最怕：拖到最后才说做不出来；准确信息、尽早交棒

光与色彩

#1 画光，而不是画素材
不要画素材，要画反射的光；看到的都是进入眼睛的反射光，由多种因素决定；树干茶色、叶子绿色就算完成？不行；硬件性能有限：用简单手法让画面更好看；森林三步：加光 → 错开色相 → 加入空气感；叫你做树，不是只画一棵树；最终输出 = 表现环境中的光

#12 让东西看起来像微缩模型
微缩照片：俯拍 → 上下模糊 → 提高饱和度 → 降低蓝色；反过来：这些处理会让大东西看起来小；景深：除非刻意，少用；观者注视点各异，看的地方糊了不舒服；苏菈参战影片：拿掉了焦点由远到近的演出；饱和度：大东西要克制，有空气透视；监修常指出：要客观看最终输出

#13 应对显示器色差
每个人的显示器色彩、亮度都不同；同厂同型号也会偏差；照明也会改变观感；对策划/程序/调试影响小，对美术和监修是死活问题；测色校色仪器有，但输出常是电视；最终：一台大家都看得见的显示器，远处目测；差距大到无法调整（超梦的阴影消失）；玩家家里的电视同样会如此；团队内要有消除色差的机制；照明尽量用没个性的

#14 动态模糊
空气滑翔机「轮子」：中央星星该做旋转模糊；方法：行驶时替换贴图；火车舞台车轮、铁轨一开始就有模糊；模糊 = 运动的残影，补间两帧之间；减少逐帧感，更有动感；刀光也算模糊，但性质稍异；不只角色，镜头移动时背景也适用；手绘或硬件计算；过头：反而违和、看不清 → 提供调节选项；越自然越不违和，期待技术进步

#15 让不存在的东西显得真实
游戏世界是布景：无质量、无判定、无重力；实感来自画面、声音、程序、参数等；让不存在的东西显得存在 = 表现；适用于所有要素，不只图形；做桌子：质感、光照、量感、生活感、摆放；普通桌子和微缩桌子形状一样，表现决定真实感；容易忽视：空气流动；《大乱斗》：环境风让摆动物飘动，爆炸附近有微风

#16 最终输出
高端机：最终输出越来越关键；帧缓冲区：图先存入，再绘制背景、角色、UI；着色器、渲染也在其中进行；全部画完才传到画面；后处理决定画面好坏；《DX》：各物体颜色鲜明 vs《特别版》：色彩混合、加入反光；多边形漂亮就行的时代结束；需要「最终输出协调人」控制后处理

可读性与判定

#2 强调有判定的东西
强调有接触判定的东西，其他不强调；动作游戏：知道哪里有地板理所当然但重要；3D 透视让判定位置难懂；背景越讲究，越可能让地形不显眼；只加空气透视易懂但损害美观；画面漂亮也重要：卖不出去就没意义；一切是平衡，稍偏游戏；美术要理解游戏机能再画

美术监修

#4 把握好尺度感
常见问题：大东西看起来像小东西（反之很少）；实物与模型形状颜色相同，尺度感却不同；空气透视、环境光、光追、移轴/微缩效果影响大（先放一边）；贴图：循环太小、材质画得太细；加大尺度、从远处看；瓦片偏色、草地色相变化；饱和度过高 → 受环境光影响小 → 显假；高光（光泽）最难：过多像玩具；限制高光面积与强度；法线贴图要匹配尺度；大型机械要有污渍；单色也混入不同色相；形状优先级较低；CG 物体通常像模型，要弥补差距

#5 用修图来监修美术
监修时，展示调整后的样子最好；命魂洞窟：色彩太朴素 → 修图；魔罗克背景、灯火之星通路：明度差与热感；熔岩不做太耀眼：伤眼；口头难传达；导演也不可能全部修图；每张约 5 分钟，最多不到 10 分钟；步骤：复制图层提高对比 → 错开色相 → 受光处擦除 → 整色；他不用数位板，只用鼠标；监修只是方向，打磨靠美术

#11 监修杂谈
远程后监修以邮件为主，但图更好懂；史蒂夫：抓取轨迹、在恶魔城暗角中也要看得见；Minecraft 夜景：火把周围更亮、周围更暗；参战影片：镜头位置图、显示优先级；焰/光：体重前倾、判定残留、残影、笑容嘴角；阿尔斯特云海：上下动太大、风车逆风转；一八：表情更怒、翅膀收得太快；三岛道场：远景信息量、月光反射、碎片打散；横幅、CM 也监修；百闻不如一见；感谢修改的员工

#17 只为破坏一面墙
最难监修：大鹏号与这面墙；先做修图展示想要的样子；断面像锯子切的 → 前后板要错落锯齿；板面别弯：保持 X，在 Y/Z 方向做锯齿；锯齿要不规则，柱子残留别规则；碎片别挡住斗士通过的中线；只要品质达标，偏离他的想象也 OK；不行时只能决断：按原样产品化；期待一步只进半步 → 大幅调整再拉回；导演与美术共同负责

#20 监修杂谈：苏菈篇
后跳：调整剪影显得更有活力；着地站位看起来偏移 → 改脚的位置；横看的游戏：挥出方向要用右图；用手办做参考修正前空中姿势；拍手：手腕要弯，否则无力；配色：A/B 部分明度差要看得出；发现小垃圾要当场指出；暴风雪特效加入暗部，亮舞台也看得见；必杀技必须检查地上与空中版本；命中星星飞远、别被大金刚挡住；空洞堡垒：海偏绿、手前强远处弱的对比；不放弃地反复打磨提升品质

像素与风格

#7 像素画的基础
初代 GB 卡比本体由樱井亲自打点；精灵：画图单位，可在画面上流畅移动；红白机/GB 常用 16×16 精灵；圆：15 点比 16 点更圆——有中线；单位粗的游戏：建议奇数宽度；两色：轮廓+高光=泡泡；网点/反转改变质感；涂黑+高光=铁球；多一色：柔边、地面反光

#18 漫画式表现
漫画表现：透过镜框看到眼睛、侧面的嘴；《洛克人 DASH》：侧脸时嘴移到侧面；不自然，但很适合动画：只换赛璐珞、嘴动易懂；索尼克的嘴也偏向侧面；挤过窄处的表现在 CG 很难（形变动画）；不写实不是回避的理由，推荐使用；卡比/胖丁嘴型：断面上方更真实，下方表现更好；别把理所当然当理所当然

#19 用设计立住角色
娜可露露：KOF XIV 模型 → 重做回经典形象；不只是照搬旧的：红色部分保留新花纹；1993《侍魂》：变形与张弛很棒；头部体量大、手脚细但足够强调——与索尼克相近；最重视剪影：涂黑也要有夸张、可辨识的形；剪影模糊或难与他人区分就不行；姿势同理；理解背景再更尖锐，全员一起立住角色

画风与统一

#8 统一画风
进入团队就要对齐同一画风；擅长写实肌肉的人也可能一直画可爱风；大多数美术能灵活适应——靠技术；概念图：把世界观、角色、道具画出来；少数优秀的人带头画；据此建模、深化光照，缩小差异；马力欧的牛仔布纹理：对齐写实与卡通；机能越高，对齐画风成本越高

#9 动画与真人之战
只照官方形象 → 画面无法统一；① 降低饱和度：更易受光源影响；② 纹理适度刻画：卡通加细节、写实减重量；③ 微调头身比（如贝优妮塔）；④ 必要的重新设计（欧力马的太空服、机器人、雪山兄弟）；⑤ 现实中可能存在的表现（闭眼皮、咬合）；别让动画和真人打架

#10 画面好坏影响乐趣吗？
游戏性与画面看似可分开考虑；但游戏性明显能衬托画面；背景 = 没有判定、没有重力的多边形布景；存在感取决于游戏内容；《黑暗之魂》《只狼》：警惕地看每个角落；同样画面换成索尼克高速跑过：印象完全不同；商店横幅不吸引人就没人玩 → 乘法；两者都拉高是最好的

动作的委托与基础

#1 动作的委托方式
动作 = 角色的动态，《大乱斗》中尤其重要；只讲概念，不讲工具；先写动作列表：全部动作、文字描述；列出动作长度与攻击发生时间；待机、步行等循环动作标为「循环」；关键姿势：手办拍照 → 调对比 → 规格书；每名斗士约 70～80 张；也会用原作截图；离人形太远的只用文字；这只是开始：手办可动范围与游戏模型差很多；全体动作设计师一起听他的指示，积累经验

#2 过头才刚好
一八螺旋幻魔脚：腰扭到权重破绽——是好动作；攻击动作几乎不存在「过头」；「完全不够」才是家常便饭；小画面里的小动作：做过头才刚好；比认为 OK 的再夸张一点；初代时骨骼：躯干与上臂相连，只能改角度；为修模型破绽而削弱势头，得不偿失；《VR 战士》：上下半身几乎反向；可动范围合理≠好；直线运动：冲过头再回来一点（卡比针刺）

#7 夸张以弥补信息损失
《钟楼惊魂 3》：深作欣二导演遗作；过场演技夸张到好笑；导演：多边形角色失去信息，要演得更大；首次做游戏却直击本质；游戏角色（含动画）本不存在 → 夸张才刚好；动作捕捉原样通常用不了；角色在画面中越小越远，动作越显拘谨；动作游戏还受博弈与手感影响，但基本要大而堂堂；挥剑不能只想着「挥剑」；注意画面存在感、大小、操作感，大胆地动

攻击动作

#3 攻击动作的拆解
四段：待机 → 预备 → 攻击 → 收招；待机：几乎所有动作的原点，先做好不动摇；预备（预备动作/蓄力）：第 1 帧大幅跳姿势；立即显示输入被接受，也促使对手回避；攻击：判定瞬间与命中顿帧时姿势要定格；收招：硬直时间，不要停在接近待机的样子；取消帧：未完全回待机就可操作（DX 之前没有）；委托时明示：待机姿势、攻击姿势、发生帧、总帧数

#4 预备动作要瞬时且有力
预备 = 按下按钮到攻击出现之间的姿势；蓄力打击：在预备途中颤抖；按下瞬间姿势大变；本应细致补间，但《大乱斗》重视响应；接受输入立即返回反应是理想；无预备也能成立：零装萨姆斯弱攻击 1 帧出；《快打旋风》刺拳：瞬间出、可连打；网络对战：蓄力可填补延迟；没有预备，打击缺乏冲击感；从传达输入接受的角度考虑预备

#5 攻击姿势
命中时有顿帧，那一刻最留在脑中；手办规格书多拍命中瞬间；整体夸张，远看也清楚；攻击要跨过中线，偏向前后会打不中；不做左右对称姿势（除非刻意搞笑）；躯干别完全正侧，稍扭出张弛；挥出一点后再顿帧命中；能承受一定透视（画面左右看起来不同）；最重要：剪影漂亮，侧面剪影是绝对；多摆弄实物培养感觉

#6 收招决定冲击力
收招 = 攻击后的破绽（后摇）；看似不重要，其实最常入眼；响应要快：预备到攻击短；有博弈：强攻击后要有相应破绽；普通攻击 1 秒内；大型突击很少超 1 秒；攻击发生约在 1/3～1/4，最快 1/5；攻击本身几分之一秒 → 收招要传达攻击；不要只是补间回待机，坚持到极限；取消帧：姿势要恢复到看起来能操作

#16 时刻意识攻击判定
侧面剪影重要，但开发中常有问题；攻击判定不贴合剑拳形状，覆盖更大；《大乱斗》坐标移动激烈 → 判定偏大；否则打不中、压力大；常见：攻击范围没过中线 → 打不中 → 要修；策划可放判定补救，但外观与判定差更大；外观与判定差一些可为乐趣而接受；动作位置不同则破绽更大；判定出现时机、命中姿势：顿帧时最留眼；挥剑时稍挥出后再出判定；动作对手感影响极大，要意识游戏本身

姿势与表现

#8 摆姿势的建议
拿可动手办玩，对动作设计师是好练习；姿势定格比什么都重要；立体物能教你很多：怎么定格、好角度；普通站立 vs 调整后：利落；避开对称、避开正面；收下巴，头颈角度不要垂直；上身、腰、腿不要串成一条直线（S 曲线）；飘动物（披巾、裙）要有动势；双臂从不同角度展示，手腕别与前臂成直线；重心略偏，脚轻微八字、一前一后；最终不是理论：是什么让人觉得好；《特别版》官方立绘也是摆姿势

#9 挤压与缩放
缩放（Scaling）= 放大缩小模型；CG 三要素：缩放、旋转、平移；移动旋转天天用，缩放却常被轻视；弹球 + 缩放：质感完全不同；挤压与拉伸：增加质感与势头；前提：保持质量——竖压则横伸；卡比下蹲 / 着地从 GB 时代就变形；单纯压扁 → 只是个椭圆，缺乏量感；要求按点阵图的量感；讨论过混合形状；马力欧出拳时拳头变大：更像夸张表现

#10 受伤动作
受伤瞬间立即换成痛的姿势；第 1 帧有顿帧 → 看得清 → 很重要；与待机姿势截然不同的极端姿势，远看也明白；并非瞬切：从被击姿势补间到受伤第 1 帧；判定拉长时会在很远处做受伤姿势——重视被打感；问题：弱攻击使对手位置偏离，连段接不上（顶节点位置）；上中下 × 小中大 = 9 种；体型独特，难以复用动作；吹飞时扭身，手脚剪影清楚；卡比 SDX 企划书：一瞬间可以这么极端

#11 补间的陷阱
2D → 3D：同姿势也丢掉利落感；工具自动补间：方便但不好；中间动作被看到 → 显得软绵；特瑞 8 帧中踢：补间版软，成品版锋利；关键帧：到达方式要极端；几乎不要中间帧；时间给预备和攻击；预备比原关键帧拉得更大；隆的下重拳：原作 3 张往返；《特别版》：右前臂后拉更多，每张 1 帧送出；收招不走同一轨迹，待机般的姿势是损失；补间要善用，但别让印象变笨重

#12 表情动画
表情（Facial）：角色小也认真做；以塞尔达为例：各种表情；不需要口型同步、细微变化 → 整体有活力；做模型前先用修图定方针；交上来的多是小变化；狼的受伤脸：修图后更强，符合下颌结构；觉得努力了再更大；睁眼时上下露白、上下门牙不咬合等要点；前沿游戏用细微差异表现情感；CG 信息少，夸张才刚好；机器人的表情也是表情；史蒂夫只有眨眼

技术与骨骼

#13 翻转动作
翻转动作 = 把姿势与动作镜像；林克（不翻转）一正一背；马力欧（翻转）都朝正面；无正式名称，开发内这么叫；《街霸 2》点阵图左右反转；《街霸 4》多边形也遵循；不必每个动作重做，但管理麻烦；右直拳变左直拳；道具要迅速换手；左右不对称（持剑）不适用；理由：好看，表情与信息量都在；《X》之前没有：跑步只能做正侧面；横看游戏中斜着跑也没问题；题外话：DJ 的 MAXIMUM、马克西姆番茄

#14 动作混合
动作混合 = 组合两个以上动作；取消帧后操作：合成姿势，不是突然切换；待机→步行 vs 攻击→步行：步行动作一个，开头大不同；可指定混合适用度与时间；中间动作增多 → 失去张弛（见补间一集）；机械补间可能破绽 → 快速完成；护盾移动也是混合：外周 × 中心；《大乱斗》中影响有限；3D 游戏更有用：上下半身分控、地形脚步、状态迁移；研究永无止境，机器人学或许相近

#15 手指的表现
手持物体时常见错误；握东西：自然是垂直于手；配合前臂挥动：斜握；坏例子：很「手办」；旧时代多边形少只能将就；用手指角度做自然握法；手指小却复杂 → 最先被削；看似在动其实固定 / 多种手指图案替换；可动手指数量曾像硬件性能的象征；计算全部手指层级是不小的浪费；省该省的，处理用在重要处

#17 骨骼的局限
CG 角色装骨骼便于动作；现实运动：根部动带动末端；FK（正向运动学）：肩→肘→手腕决定位置；IK（反向运动学）：拖手的位置决定肩肘角度；IK 编辑方便、易贴地，历史很长；结构单元叫骨骼 / 关节；关节可动极限 180°，想弯得更过；单纯反向弯会让 IK 难用；多关节可行，但有负荷、需卡通感；《大乱斗》开发初期提过，未实现；超越常识处才有动画之美；别被便利系统画出的极限线框住

#18 双轴旋转
只绕 Y 轴转头 → 很机械；旋转用 X / Y / Z 轴表示；绕竖轴的转动也别只用 Y 轴；动人时意识双轴旋转；低头再转：X + Y；侧倾再转：Z + Y；手腕单轴像钻头，稍倾再转更像样；联动肩与锁骨（如拧摩托油门）；函数曲线默认也行，但可错开两轴时机；有时加反动；终点相同，过程不同 → 性格不同；转头时也要意识视线

特效基础

#1 让特效「脆」起来
特效 = 画面效果（如打击火花）；讲他监修范围内的抽象特效表现；多用颜色加算：叠加后趋近白色；加算 ≠ 半透明；层层叠加就像样；别依赖加算：发雾、无张弛、太亮；只在暗背景显眼；推荐：与清脆（实色/多边形）特效并用；《特别版》特效全面走清脆的动画风；混入暗色，亮背景也看得见；用相反的元素互相衬托

#2 让角色从特效中凸显
特效埋住角色很常见；2D：提高角色显示优先级即可；3D（非俯视）难免被埋；强行优先显示会像视差错误，印象不佳；力量灌篮：皇冠特效中仍看得清；隼龙拳：本该被填满，仍部分可见；舞台内侧与外侧的山高不同，不挡中央角色；必杀/最终技特效也不埋人；另一种方法：给模型描边

#4 慢动作下的视觉特效
特效一瞬间传达大量信息，难以看全；本集：慢动作 + 关闭背景录制各种特效；仔细观察是做任何东西的捷径；也能好好看清动作；观察要点：闪光→主体→余韵的顺序；观察要点：亮色中混入暗色、实色形状；观察要点：火花、烟、冲击波等点缀；结尾：特效开 vs 关——关掉很朴素；想让游戏活起来，就放满令人兴奋的特效

#5 画面震动
画面震动最适合表现巨大冲击，应积极加入；樱井从《梦之泉》起就重视；过度会看不清，需注意；方法 1：移动摄像机（3D 空间）；缺点：远景几乎不动；方法 2：移动绘制后的画面；全画面（含 UI）都震，边缘可能露黑边；多用前者，但要考虑注视点如何动；注视点可与摄像机同步，甚至动得更大；《大乱斗》：大/中/小/极小 + 持续；大中小不只缩放，震动模式本身不同；小只纵震，中加入横震；持续性震动：传达地形震动的纵震；按镜头远近改变幅度，也影响画角；平面世界等画角窄的舞台要调整；先强后收敛，带舒适的随机性；以前用鼠标乱晃录下动作做基础；没有震动的游戏很乏味

#7 广告牌（Billboard）
广告牌 = 永远正对镜头的平面物体；多为两个多边形组成；《马力欧 64》铁球：一张无动画的图；炸弹王：眼睛王冠是模型，身体是广告牌；粒子等特效一般用广告牌；停住爆炸转镜头：其实是平面图（再加火花等）；2D 物体绘制成本低；适合闪光等无实体的特效；《大乱斗》食物一直是广告牌 → 转镜头会怪；Y 轴广告牌：只绕 Y 轴面向镜头，用于特效可能显得太瘦；如今画面精细，几乎看不出，意识也淡了

#9 特效的尺度要对
角色、舞台、特效都要尺度感正确；火焰常见：大火看起来像蜡烛、火把；原因：密度不够；焰之剑的火焰：交上来的像蜡烛 → 给出要求的密度示例；成品：受贴图容量所限，仍差一点；办法：增加循环次数、用更小更细的粒子；太执着会吃贴图内存；特效一直在动，不必太细；关键：粗犷、快速；不限火焰：对世界大小给出正确尺度

#11 粒子特效的局限
粒子 = 大量喷出的特效（含广告牌）；初代卡比已有类粒子表现；机能提升，制约减少但不为零；原则一：寿命短，以速度补偿；原则二：多个粒子画在一枚板上（泡泡）；原则三：错开出现时机，减少同时显示数；原则四：错开位置，避免重叠浪费；原则五：每枚画大一点，物尽其用；《铁拳 7》特效丰富令人羡慕；镜头、命中量不同；在可容许范围内追求最大效果；初代卡比：每帧手工摆星星，只有座标数据；吸入：随机移动模式，黑白点混合耐任何背景

爆炸与打击

#3 闪光、爆炎与烟
常见错误：火焰冒一下就完；《星际力量》（1984，Tehkan）5 帧爆炸；闪光：瞬间告诉玩家这里发生了激烈之事；闪光持续较长；纯白在白背景看不见 → 混黑；冲击波与光晕；爆炎：决定爆炸性格，从中心喷出，加火花；判定不必持续整个爆炎；黑烟接棒；火焰带余韵；收束：太短没有手感；画面闪光、画面震动；地面与空中爆炸分开

#6 命中标记（Hit Marks）
命中时的特效 = 命中标记；樱井作品多华丽、漫画式；写实系容易违和，按作品平衡；也可用飞溅等替代；防御标记也是一种命中标记；① 与效果相称的华丽；② 对比分明：线细、加算混合不清楚都不好；③ 命中位置合适：攻击判定与受击判定重叠处；《大乱斗》镜头拉远，攻击判定偏大，位置难定；④ 多要素并用：冲击波、上飞的飞溅、对机械出火花；适时混入多种颜色，抗背景变化；⑤ 不过度遮挡角色；⑥ 停留时长：连击短、其他长，但尽早淡出；⑦ 明度差：明暗背景都可见，铺黑色；hit stop 期间标记继续动，要有效利用；特别版：受击方在 hit stop 中操作会显示吹飞方向

#8 刀光（风切）
风切 = 挥剑留下的轨迹（残像）；2D 也常用，但 2D 与 3D 做法差别大；《大乱斗》拳脚也有类似风切；做法一：沿轨迹生成多边形（扇形），尾部半透明消失；剑速快，只追轨迹会变粗糙；侧面看可能几乎看不见 → 改动作；单纯水平斩通常不好；做法二：板多边形一枚，1 帧挥完时瞬间显示；命中有顿帧，所以看得到；露琪娜标准蓝、马尔斯强调刃尖、艾克豪剑、炎燃烧、Mii 按武器重做；没有风切，手感差很多

#10 闪烁效果
闪烁 = 让画面或角色一亮（自创用语）；如今规范严，旧作移植也温和；画面闪光：大面积增加手感（同画面震动）；角色闪光：强调状态变化；方法：颜色加算或专用光照；均匀加色 → 对比降低；白闪在亮画面反而不显眼；以前：闪光中混入亮与暗；《特别版》：命中闪光加阴影；镜头拉远时闪烁更强；白闪 = 无敌；黄闪 = 被投后不可抓；边缘光：无敌等状态；闪烁多为一瞬；液晶响应速度影响观感

音乐

#1 让节奏配合游戏
游戏声音：音乐、效果音、语音等；节奏 = 拍子的快慢，BPM；有合游戏的节奏、不合的节奏；依赖个人喜好，但要有意识；BPM = Beats Per Minute；每秒一拍 ≈ 60；每秒两拍 ≈ 120；《大乱斗》对战曲多为 130～170，少数 200；攻防速度决定合适节奏；同一游戏场景变了，节奏与节律也不同；不只作曲家，大家都要考虑；《DQ1》越深越慢：有效但少见

#4 游戏音乐与环境音
常见疑问：老游戏音乐好记，现在的「好莱坞化」；实验：给现代游戏配红白机音乐 → 很吵；画面进化，视觉信息增多；音乐太突出不再合适；写实画面需要环境音：风、踩土、装备碰撞；声音元素太多，要考虑各自存在感；但曲子确实太多；曲子多 → 难记、难嗨；适度控制、善用；做主题曲 + 改编用于各场景；记住主旋律的曲更有效；贴合玩家的情感

#7 音乐的改编
《大乱斗》：很多作曲家、很多改编曲；① 樱井从各作品选候选曲（多于实际数）；② 召集音乐家说明注意事项；节奏感、曲调要适合对战；配合 3-2-1 开场；前奏可在计数后开始；原曲短 → 主旋律后混入他曲；变调等抑扬；最后走向高潮；循环点可设在前奏前或后；限时 2 分（《特别版》2 分半），结束时略听到循环开头；③ 让作曲家选有感情或擅长的曲；④ 带回制作，樱井全曲监修；监修经声音导演转达；常见指示：节奏感、抑扬、再现度、方向；主旋律要与原曲一致

#8 原曲永远是对的
《雅典娜》改编：调整方向与监修相反；起因：对「主旋律」的误解；玩家（游戏/红白机版）听来主旋律是 A；乐理上主旋律是 B；无论乐理如何，原作中听到的曲就是正确的；奇妙段落：先合拍，再变反拍 → 照样再现；《超能力战士》（1987）：号称首款认真唱 BGM 的游戏；古代祐三改编，加奈子演唱，樱井在场；日版原曲三段，英版只有一段；《大乱斗》：日版三段；英版第二段器乐、第三段人声回归；原作一段后切换到内置音源；连日式英语的发音也再现；不要损害玩家各自的体验

#12 用其他曲子作参考
觉得某现有曲非常合适 → 委托「像那样的」；作为参考很有用：具体线索；危险 1：导演被那首曲支配，听什么都像假的；危险 2：作曲家被支配，「相似但不同」很痛苦；不清楚要改什么 → 迷失目标；《神之手》第一关「Jeans Rock Eye」：委托「像 Ventures」；并非要那段吉他，最终保留冲浪摇滚感；有时直接与版权方谈判使用原曲；《俺之尸》的「花」：增田直接谈下；参照作品时可减可增；新作品不是他人作品，要灵活推进

#13 红白机与 NES 的音源
一台硬件进化如此之大：空前绝后；构成：方波 2、三角波 1、噪声 1、DPCM 1；波长长 → 低音；短 → 高音；方波：像城墙垛口，「哔」的清脆音；占空比 12.5/25/50/75% 改变音色；三角波：柔和/闷，多作贝斯（准确说是伪三角波）；噪声：打击、爆炸、欢呼、海浪；5 个声道兼顾音乐与效果音：响效果音时消掉部分音乐；DPCM：采样音源，如《马力欧 3》定音鼓；吃容量 → 初中期少用，后期大进化；磁碟机：波形存储音源；卡带内置扩展音源 IC；海外无磁碟机；NES 删除扩展音源针脚 → 日美音乐不同；推荐《银色冲浪手》、Sunsoft 小高直树

#14 没有哪部名作的声音是差的
这个频道说的全是个人意见；结论：没有声音差的名作；玩得越多越确信；例外：很久以前完全没声音的游戏（《Rogue》）；只有简单噪声效果音的作品，声音也构建得好；画面差的名作有；本质不连贯的名作也有；声音差的名作：一个也想不到；「声音」包括音乐与效果音；好恶因人而异，无法断言好坏；回想名作，先浮现的常是音乐与效果音；声音比游戏本身、画面、角色更直击心灵；例外：手游、静音玩的掌机、环境嘈杂；能无拘束地听好声音，乐趣会更多

效果音与语音

#2 平衡效果音
效果音几乎一直在响；要考虑音量、华丽度、显眼度；走路 vs 剑空挥：都小，优先谁？；原则：与玩家关系越大越大声；最大：击坠（决定胜负的大事件）；其次：命中与被命中、完美防御；必杀技（非命中）；语音同等但需平衡；爆炸：命中与必杀之间；回避、护盾、抓崖等条件动作；空挥、弹摇杆冲刺；跳跃、着地（着地稍大；按服装材质重做）；步行：几乎听不到但有个性，需变化；3D 游戏步行可更优先；材质属性；别只看声源大小

#3 在多种环境中试听
检查声音必在多个环境对比；耳机、电脑音箱、廉价电视；电视小喇叭低音几乎全无，缺乏魄力；但电视最普及，最多人在听；录音室精调也要，但别执着于细腻；准备不同环境，逐一解决问题；贴近玩家的环境；难换耳机：基准偏移；Switch 本体喇叭：清晰，掌机模式常静音 → 不太重视；别只用录音室大音箱收尾；题外：隆的命中音最难（还原街机音箱氛围）

#5 虚构与写实的声音
格斗游戏若用真实声音，不会被接受；《街霸 2》升龙拳：声音满是谎言；像昭和黑帮电影的夸张；日本（不止动画）有夸张声音的文化；画面越写实，夸张声音越违和；完全写实：打人只有「啪」，不够；格斗游戏与真实格斗相距甚远；写实声音能给无意义之处赋予意义；《我的世界》：声音补足信息；合成时的敲击声让人想象做了什么；粗糙方块也有木与石的重量；夸张与写实，按游戏取平衡

#6 语音录制
做一个斗士至少一年；语音录制每人约 1 小时，含影片也不到 2 小时；时间短，但声音直接进游戏，存在感强；① 选角：多半原作已定，尽量贴原作；② 台本：竖排；常规动作套用；特色台词；原作参考音源；台词短、频率低：长台词与多话减损沉浸；避免撞声：库巴、大金刚保持兽性；③ 约录音室（万代南梦宫工作室）；④ 录音：介绍角色、复听原作；樱井用对讲按钮直接指导；海外语音：NOA / NOE 主导；录后编辑很辛苦；尽量让搭档一起录；玩家可能比开发者听得更多 → 责任重

#9 起音要强，余响要轻
命中音波形：开头响亮，随后余响；交上来的音常余响很长；4～8 人对战，效果音成为噪音洪流；调整 1：起音强（Attack 强）；起音快，且最开始就是峰值；命中音不能延迟；调整 2：余响别拖（Light Reverb）；有余响显得强而气派，但会被下一个音糊掉；攻防快，声音太多就听不出起点；弱攻击连打时要保留连打感；强攻击：顿帧期间主要部分结束；方针：起音强、余响适度；不只好听，要合游戏目的

#10 如何对效果音下指示
声音没有实体，监修指示极难；不是模仿声音就能解决；用具体表达：如「起音强」；大家都知道的可以比喻：「像喷气机」；不是人人都知道的例子别用；有时给 YouTube 上相似声音的链接；远程工作：邮件里写「哐」「砰」没意义 → 尽量避免拟声词；但声音负责人：偶尔有拟声词有帮助；团队像在找他脑中的声音；不必与他想象完全一致，合游戏目的就 OK；有时会超出想象；前提：一开始就要有明确的形象

#11 环境音的平衡
《大乱斗》也有环境音，种类意外地多；优先度中环境音最低；太响会盖住关键效果音；但不是完全听不到；环境不同，声音回响不同；好音箱环境下要有扎实的环境音；停手时一片死寂 → 没氛围；游戏要让人感到身在那个世界；主观、第三人称越肩视角尤其重要；与需夸张的效果音不同，写实的声音行得通；卡通风游戏叠写实环境音也没问题；影视作品的经验容易通用；毫不松懈地设置，增加沉浸

UI 基础

#1 易懂与风格
UI = 用户界面：菜单、画面数字等显示；手柄也算 UI，但这里只谈画面显示；易懂与风格也许是对立的；「风格」因人价值观而异；《女神异闻录》：风格化 UI 首屈一指；但难说整齐，一眼难懂；《P5》若用规矩菜单就太无趣；UI 是抽屉，装的东西多少因游戏而异；不能简单说易懂即好 → 合游戏目的；他的作品服务太多，抽屉太满；建造类：《我的世界》的仓库 = 自己建文件夹；下功夫：视线诱导、大小、窗口关联、亮度/饱和度、字体；没有正解：合游戏内容与世界，再尽量亲切

#2 文字大小
用日语玩海外游戏：字常常太小；合适字号因语言而异；汉字占较大空间；日语：一字信息多，句子短；英语：字母简单，小也能认，但更长；法语：往往更长；只按英语布局、不灵活 → 字太小；如今减少：开发者更在意、分辨率更高；可选字号：非常周到；留白多的时尚画面更容易做；Switch 掌机前提：字较大，掌机上一定检查；字太大会减少酷感；红白机 8×8 点写汉字：大脑会补全

#4 读盘画面
数据读取不可避免；只是等着看「Loading」不受欢迎；用演出弥补读取时间；初代《生化危机》：开门演出 = 后台读取；读取时间与必然的演出完美配合；加读取标志会扫兴？；但那是几十年前；如今讲求速度，读取也很快；至少显示在读取，更容易接受；做不到巧妙演出，就老实显示；开发中与完成时读取时间不同（完成时更短）；别依赖演出；简洁、不土气、随处可显示的标志；「Now Loading」文字已少见；让它为游戏世界的氛围出一份力

#5 文字的强调
读文本的作品可控制文字；改大小、颜色、动画、字体；画面震动、闪烁也相近（本集只谈文本）；未必合严肃作品；更好传达角色情感，给无机展开添色；系统上要能设置；让翻译者直接调整脚本（设定演出的数据）；别全由原开发方设置；各语言合适的强调方法不同；日本漫画文化：书写文字（拟声）、漫符（汗、青筋）；字体、吹泡的区分也丰富；只用同尺寸文字淡淡推进太可惜；由各国母语者连演出一起考虑

#6 菜单决定世界观
同一游戏性 + 内容，UI 与字体能改变目标人群；酷 → 大人也能玩；可爱、恐怖、明亮华丽；电脑世界、和风、西洋风、中华风、亚洲风；只换字体就能构成世界观：相对轻松；但有时要从零做字体，未必轻松；实际还要配合背景、框、图标；塑造世界氛围的效果巨大；保持易读的同时积极设计；字体与 UI 是构建世界的一部分；近乎为世界打包；颜色与装饰也重要；当下偏好简洁，但也要关注字体

#7 给游戏做色彩分区
他导演的作品常按颜色区分菜单；《特别版》：顶层分色；「大乱斗」= 红系，子菜单也以红为基调；「命魂」= 绿系；很早以前就这样做；未必总是好事：涂满颜色显得低龄；每个游戏有自己的调性（tone & manner）；推荐：同一画面不要混杂颜色；《3DS/Wii U》：大幅角色画却不显乱；图像会被刷进记忆；找图比读字快得多，更直觉；左脑读字后理解 vs 右脑凭图像理解；最终优先游戏调性，每个游戏有自己的正解

操作与便利

#3 现代的便利功能（设置项）
大作应把设置做得周到；参考：《最后生还者 Part I》的设置；无障碍：利用的便利性，也包括让有障碍的人能操作；项目数量惊人，有重复但仍了不起；HUD 大小可调，并有即时预览；色盲模式、高对比显示；放大镜功能；晕动：屏幕中央常显点；导航：前进方向箭头、坠崖振动、聆听模式增强；可跳过解谜等，影响难度；文本朗读、电影描述、音频提示；战斗无障碍：先「解锁」再开，防误设；无敌切换、慢动作；预设一键设置；操控：命名方案、横握/倒握、左右摇杆互换；十字键长按切换，避免与短按冲突；显示默认按钮；字幕：大小、背景、名字、颜色、说话方向；画面：画质/性能、高帧率、亮度预览；玩家多样 → 按喜好设置是必要的

画面信息

#8 重要的东西就做大
按重要度改变图标大小；一般菜单从上到下排列；《Meteos》以后菜单多图标化、分大小；越大越常用、越优先；目的：引导玩家访问；GameCube 手柄：A 大、X/Y 小；不只看，摸也知道该按哪个；并非适合所有游戏；选项价值完全相同时反而难操作；例：用四个按键上下左右移动菜单；改变选项权重 = 损失通用性；图标化菜单在翻译时文字易溢出；适合日语的版式

#15 HUD（抬头显示）
HUD = Head-Up Display 画面上的信息；源自战斗机/汽车：视线不用移开；游戏 HUD：贴在画面上的表示；跟随角色的表示更像 HUD；日本作品信息多，海外作品克制；海外重沉浸；不少游戏可随时隐藏；樱井偏功能、全部显示；有用却杂乱，各作都在摸索；《X》起显示斗士头像，强化角色性；背景纹样 UV 滚动，有战斗燃烧感；斗士重叠时 HUD 半透明；1P 光标按距离/状况隐现；《卡比赛车》仪表随能力变化、机体坏掉仪表也坏；用图标显示攻击/击败的对手；前提：让游戏更好玩、更易玩

操作与手感

#9 我想快点选！
任天堂开发新主机时会征求提案；樱井多次提议：手柄加滚轮；滚轮能让菜单选择极快；游戏中「从多个对象里指定一个」的场面很多；带段落感（咔哒）的滚轮更有实感；理解硬件放不下滚轮的现实；摇杆「咚咚咚」选菜单他并不满意；新设备出现就想想能否用于 UI；但只给熟手的捷径会降低普适性

#11 按键设置
再简单也要能改键；改键画面规格很重；最好由主机统一按游戏定制；《大乱斗》从 Wii 起支持多种手柄；多人聚会游戏要方便客人设置；用图形化手柄表现，而非纵列文字；用光标选按钮，进入后再按要分配的键；不采用「按下要换的键」方式：退出键会被误改；允许操作重复（两个跳跃键）；键位记在「名字」里；可存进手柄带着走；日本 PS5 起 ×确认○取消；Switch 系统换键会影响全部软件；游戏内无按键设置就无法应对

玩家体验

#10 让玩家跳过，让玩家暂停
不在游戏的瞬间必须能跳过；能一次全跳最好；担心跳过后看不懂剧情？玩家不一定是第一次看；没存档也不代表第一次看；影像不能快进/跳过就是不便；标志受规定限制不能跳？早就不流行；定规定的人也应以可跳过为前提；实机演出按台词跳过已是主流，也适用于过场；过场必须能暂停；电话、来客、饭好了…停手的理由太多；网游进度另当别论

#12 推进文字
人读文字通常很快；能快速推进文字很舒服；樱井自己读游戏文字就这么快；精细演出的过场无法按想要的速度推进；翻书 vs 看电影的差别；希望过场也能尽量快进；逐句跳过台词：直接跳到下一句开头；让文字和对话容易快速推进；或边玩边听对话；订阅服务和 YouTube 的影像看不完；倍速播放很多人在用；用尽量少的时间享受尽量多，已是现代文化；系统支持后，慢看快看由玩家选；海外作品多默认关字幕，观念可能不同；慢慢推进的场景，现在还合适吗？

文字与信息

#13 给菜单加上说明文字
菜单项多为单词，未必能看懂；帮助文字：在画面下方用文字说明功能；应积极加入；樱井作品几乎都有；绝不用菜单同样的词来说明；「选项：前往选项」是反面教材；用不同的词说明；作者想好后再进一步嚼碎；意译而非直译；「单人模式」不如「一个人玩」；避免「Config」「Key Repeat」等术语

#14 不靠文字也能明白
尽量做到不懂语言也能玩；图标里尽量放入画面/角色；好看之外，看图就知道能做什么；换成韩语界面也能大概理解；频道中尽可能用英文画面；日本人读英语还能猜，反过来很难；连按确认键直达基本主游戏；《特别版》连按到大乱斗选人；《卡比赛车》连按开始第一关；《卡比超级豪华版》连按进入带教学的第一剧本；这是有意设计的

开发流程与规范

#1 文件名要有逻辑
开发名称 SpecialHi = 「必杀技·上」；Attack = A 键普通攻击，Special = B 键必杀技；数字表示强度：11/12/13 → 3 → 4；方向：N / Hi / S / Lw，空中加 Air；一看就懂 + 排序整齐；方向放前面会排得乱七八糟；正式名按操作顺序：先方向再按键；别用罗马字文件名

#4 用工单管理任务
工单 = 服务器上的数字任务；交接后谁持有谁负责；做一个角色：规格、模型+rig、动作、程序、特效、音效、平衡…；不遗漏、不忘记；上下游可跨职种共用工单；别太串行；状态：进行中、完成、保留、废弃；期限便于发现延误；调试也用工单

#7 多人如何编辑同一批文件
游戏制作物分成无数文件，随规模增长；文件全部放服务器，由管理工具监视；编辑前上锁 → 编辑 → 上传 → 解锁；大文件一次只能一人编辑，效率差；撞车时工具尝试合并，矛盾要手工修；「回退」：别人的编辑消失回到编辑前；每次编辑有备份，运气好能恢复

参数与调整

#2 让游戏便于调整
想调整的数值都放到程序外；攻击力 10：机制在程序，10 在参数里；程序是骨骼，参数是肌肉；Excel 管理：隐藏低频参数、写公式做相对调整；「转换」：Excel 插件一键送到开发机；初代/DX：转换约 10 分钟，樱井用文本编辑；现在：更多人可以试错

#3 把参数放进括号
程序 = 步骤书，参数 = 血肉；流程：总监构想 → 策划写规格书 → 程序实现 → 策划调参数；程序完成后，参数调到最后；规格书要明确哪里参数化；①参数名用口语写；②用【】括起来；③数值用 ○ 表示；适合个别规格，不适合通用参数

#6 《大乱斗》的击飞
攻击力越高 × 对方累积伤害越高 → 飞得越远；矢量：全方位细分设定击飞方向，可沿攻击方移动修正；实际轨迹还取决于被打方的下落加速度与重量；反应影响值：给击飞乘倍率；反应加算值：无条件加的击飞力，保证最低反应；加算值常与影响值并用；反应固定值：无论伤害多少都固定反应（如超级跳跃拳的连段）

技术与工具

#5 家庭 BASIC（Family BASIC）
1984 年发售，接上红白机当游戏电脑；程序容量仅 2KB（约 2000 字）；HuBASIC 的红白机定制版：精灵控制功能强；6 行 MOVE 程序即可让角色动起来；MOVE 命令易用但只有 8 方向、难用；用 SPRITE 命令自制带惯性的操作 → 学到手感，帮助了初代《星之卡比》；属性：16×16 共用调色板；电池备份保存程序；先做做看最重要

#8 调试模式
调试模式：开发中各种确认、测试、分析用；《大乱斗》可把所有人伤害设为指定值；没有时得想办法：把狐狸横强攻击力设为 100；训练模式击飞轨迹原为调试功能；「今日一张」用调试模式拍：暂停、换斗士、镜头；限制：不能把斗士放到前后景、手持物会消失；推荐：一个手柄完成调试操作；成品通常拔掉，但影响开发效率，要整理

#9 透明化功能
可指定模型的一部分半透明或消去；目的：仔细确认动作，如披风挡住姿势；以前要靠缩放或改模型来去掉披风；开发组外的确认也有用；某 3D 格斗游戏现场也能去掉衣服和摆动物；实装后马上拍了「今日一张」；按元素开关显示：UI、2P、特效、阴影、后期效果

宣传的基本

#1 宣传是乘法
不被知道 = 不存在；开发与宣传是两个轮子；开发 × 宣传：成果互相成比例；2021 年仅 Steam 就有 1 万多款新作；樱井检查官方推特/网站文案并提案；过度刷屏会招人烦，但适度「做过头一点」可能正好

#2 准确传达游戏的样子
玩之前只能靠标题、包装、截图、影片；体验版很费力，不一定能做；别让商品印象与内容不一致；脱节：触达不到目标客户，还让误买者失望；起名时想想 4 字简称（スマブラ）；卡比 SDX 桐木盒：表现上抓住本质

#8 目标客群与市场调研
目标定位：按年龄、性别、喜好划分；营销：调查已有作品的倾向；构思新游戏时别太当真；用户界线很模糊；初代卡比：目标是「新手」，不是年龄；市场调研 = 别人走过的路，追随会变平庸；FC/SFC 时代：一窝蜂做 RPG → 红海；开新路的人孤独，却开拓地平线

宣传手段

#3 体验版
体验版有效：被知道总比不被知道好；不是切一段就行，可能等于一款小游戏；防泄露：仔细剔除剧透数据；两个版本：管理、更新、调整、调试都分开；剔除要素易出 bug；平衡未调好；发售后再出体验版效果微妙

#4 官方网站
仔细浏览官网的人比全盛期少；大作官网短期不会消失：完整而正确的信息很重要；SP 官网：斗士、玩法、场景、道具、音乐、影片…；做成适合该作品的形式；初代：不被理解 → 资料寄给杂志 → 樱井亲写 HTML 的「大乱斗拳」；苦涩经历可以成为日后的养分

#5 参战影片
X：亚空使者影片作为奖励，却被提前上传；改为与进度无关、谁看都有趣；共 37 部；几乎全部由樱井写剧情大纲（唯一例外交给 Monolith Soft）；分镜 → 动态分镜 → 预演 → 制作 → 音响；游戏部分：调试与回放功能拍摄；常见指示：更大胆、调视角、增互动、平衡严肃与搞笑、对准音乐

#6 快让人看到实际游戏！
宣传影片必不可少，没有就免谈；别让开场动画、角色介绍拖太久；有的 Steam 页顶部影片完全没有游戏画面；知名系列/制作者可用预告式，新作和独立游戏要马上展示；片头 logo 太长让人养成跳过的习惯；例外：融入游戏系统的影片、诚实的技术演示；演示就是速度

#7 在别人面前玩游戏
「樱井政博的○○」、DLC 发表、游戏设计师大赏；台上环境差、操作难；必杀技和终极必杀全部用出；不赢得太悬殊；多展示普通招式：尽量多拿素材；不理解游戏就玩不了；当面演示是最有效的演示；想象演示能整理思路

#9 大乱斗拳!!

#1 打倒延迟！

游戏与社会

#2 游戏奖项
你觉得好的就是第一；不太赞成在多元价值中排第一；游戏的好在于各自的方向，不是排名；奖项的意义：让制作者和支持的粉丝高兴；颁奖现场制作者会很开心；别把奖项当作比赛；抬高一个不代表贬低别的；团队受到表彰意义重大；游戏设计师大奖：由做独创作品的导演投票；被说「你算老几」也有觉悟；日本游戏大赏以票数为主，难免变人气投票；商业之外的独创性也值得被拾起

#4 游戏的价格
常被说游戏贵，樱井认为很便宜；个人见解，各国感觉不同；能花这么多时间的东西却是这个价格，很少见；日本电影票贵；吃饭、电影、赌博、兜风、旅行都很花钱；游戏能玩几十小时，3A 也不到 1 万日元；小规模作品 1000 日元档，社交游戏甚至免费；每款游戏背后是团队与项目；规模和制作物比过去大几十几百倍，价格没怎么涨；要养大量员工，宣传销售也花大钱；更便宜划算的娱乐：订阅服务；对消费者是好时代；对制作者：确保成本的喜悦与和旧作竞争的痛苦；游戏也有订阅；没人玩的游戏免费也没人玩；想玩、想支持的就毫不犹豫地购买或游玩

#10 与过去竞争

没问世的作品多得是；多在公开前中止，玩家不知道；其中也有令人惊讶的系列作；对谁都不好，应尽量避免；开发者很可怜：几个月甚至几年的心血；但公司职员仍能领工资（若公司还在）；受冲击最大的是公司：收益全失、维持费成亏损；一部失败就可能让公司倾斜；资金紧张时停掉前景不佳的项目；判断依据：今后费用 vs 预期收益；也可能大卖，但没苗头时难以乐观；开发后期最花钱：调试、宣传、人最多；及时止损也是正确的经营判断；开发者也要意识到中止风险；别以为完成分内工作东西就能完成；越能俯瞰全局越有利；游戏能顺利发售值得感恩

#18 《大乱斗X》团队是怎样组成的
樱井已离开 HAL，成为自由人；2005 年 5 月 E3 前一天任天堂宣布新作《大乱斗》；樱井在台下，事先完全不知情；岩田在洛杉矶酒店顶楼请他尽量以导演身份参与；发表理由：Wi-Fi 网络服务日美最期待《大乱斗》；开发体制未定就先发表；自由人的樱井已接了别的委托；若拒绝：可能只做 Wi-Fi 对应、DX 的 26 名斗士不动；青沼：樱井不参与就意味着《大乱斗》的终结；下定决心，推掉除《甲虫王者》外的全部工作；任天堂在东京以樱井为中心集结团队；主体是 Game Arts（宫本茂介绍）；DX 手柄摇杆磨得像橡皮；高田马场新办公室，10 月初开发；约 100 多人；系列存续：去属人化 vs 现在想象不出没有他的《大乱斗》

#22 创作者也会改变
樱井入行早，周围都是前辈；年纪增长，前辈越来越少；中途离开游戏业的人很多；也有只是不知去向的人；别说「那家伙完了」；有人在别的行业大获成功；有人取得专利赚了大钱；有人在与游戏无关的领域做先进的事；不显眼也可能找到了充实的工作；经验积累后做别的事很自然；一直站在同一位置反而不普通；创作者未必一直做粉丝想要的事，但别否定；也许在别处更被需要；每个人有自由选择道路的权利；樱井：目前还在做游戏，但也做起了这个频道

#24 把送礼变成游戏

游戏史

#13 Famicom（与 NES）
樱井开发过 FC 游戏《梦之泉物语》；同龄导演中开发过 FC 的很少；FC 1983 年 7 月 15 日日本发售；当时出类拔萃：画面、音乐、流畅高速、好用手柄、不贵；《大金刚》几乎原样在家玩，冲击巨大；樱井 1983 年就买了；方形橡胶按钮；方形按钮会陷进去回不来，后改圆形；NES 1985 年登场，北美最先；两年间日本游戏技术大进步；《马力欧兄弟》24KB → 《超级马力欧》40KB；NES 豪华套装附 R.O.B.；容量扩大 + 定制芯片让 FC 不断进化；日本 FC 有扩展音源针脚，音乐更好；《DQ3》成社会现象，深夜排队；卡带对孩子贵，但大家互相借；没有 FC，游戏业会是另一个样子

#14 初代《星之卡比》开发秘话
2017 卡比 25 周年交响音乐会的演讲；1992 年 GB 初登场，当时没有复制能力；1990 年 5 月企划，樱井 19 岁；给初学者传达游戏乐趣；熟手 20 分钟通关；全球 500 万本以上；开发工具：Twin Famicom + 轨迹球；FC 上就能画点阵、组角色、做动作、做背景；按 512Kbit（64KB）设计，最终 2Mbit；瓦豆鲁迪/瓦豆：用 1.5 只的容量做 2 只；戈尔多、波比兄弟用翻转省图；威斯匹伍兹：翻转拼接，攻击容易打中；8×16 点单位造成浪费；第 1 关全部角色就这一张；樱井亲手画大部分点阵；敌人不做地形判定：预先做动作再摆位；用光标打 16 进制数值；优点：处理轻；企划书已写出《大乱斗》式吹飞规则；卡比本来是不可思议世界的不可思议生物；魅塔骑士面具三种都正确；《超级豪华版》试作角色在 FC 工具上做

#21 Game & Watch 的液晶图案
Game & Watch：任天堂 1980 年起的 LSI 掌机；《大乱斗》开发时获得液晶图案资料；用于「平面世界」等场景与 Mr. Game & Watch；经任天堂特别许可公开；液晶每个图案固定位置，点亮/熄灭来表现动作；角色所有姿势同时画在一块液晶上；互不重叠地排布，是当时的智慧；看着就有趣，能感受那个时代的风格

#23 很久以前，像素画是用数字画的
80 年代前半，微电脑上做游戏要自己打点；几乎没有绘图工具，用数值打点；16 进制：0～9 后接 A～F，F 之后进位；1 位 16 进制 = 4 个点（8/4/2/1）；2 位 = 一行 8 个点；8 行 = 8×8 单色点阵；在方格纸上画再数出来；樱井：画十字线按大致位置读取；课堂上借同学的口袋电脑改游戏；彩色：两张同尺寸点阵叠加；都无 / 只有 1 / 只有 2 / 两者 = 透明 + 3 色；数据压缩：0x8 比 00000000 短；现在轻松，但技术复杂得多

#26 1986：传说之年
樱井心中最厉害的一年：1986；2/21《塞尔达传说》；5 月《热血硬派》（热血系列起源）；5/27《勇者斗恶龙》；7/30《大盗伍佑卫门》；8/1《女武神冒险》；8/6《银河战士》；9 月《泡泡龙》；9/26《恶魔城》；12/10《R.B.I. 棒球》（职业棒球家族）；12/19《光神话》；这些系列几乎都以某种形式进了《大乱斗》；磁碟机发售，容量飞跃；大容量 ROM（Mega ROM）登场；家用、街机、PC 互相竞争；1986 年 NES 在欧洲发售；隐藏角色与秘技流行；另一面：庞大化、高难度对不知情者很严苛；同年皮克斯《顽皮跳跳灯》公开；我们站在先驱开辟的道路延长线上

#30 显像管（CRT）显示器
显像管是漏斗形真空管；电子束照射荧光体发出红绿蓝；逐行从左到右高速扫描，靠残像成像，略闪烁；SFC/N64/GC 时代仍是 CRT，开发环境的电视很大；每家公司都有人在电视上摆高达模型；反应快：不经缓冲与图像处理；高分玩家偏爱 CRT；荧光体发光，画面亮丽、可见光晕；光线枪：枪是「看」画面的摄像头；扣扳机瞬间画面变黑，判定物显示白框；液晶难以实现；NTSC 525 条扫描线；隔行扫描：先奇数行，再偶数行；一般影像两场同图 1/30 秒；游戏机奇偶场画不同图 → 60 帧；有效扫描线约 490 → 画面边缘看不到；安全框外可能有角色破图，当时没问题；方格点阵等在 CRT 上质感完全不同

卡比系列

#1 《星之卡比》（初代）
企划概念分类：按顺序讲他执导作品的核心；初代卡比是导演出道作，19 岁写企划书；先帮其他作品，后来才开发；觉得「利用敌人」很有趣；原因：风险与回报表里一体；洛克人是通关后得武器，不太一样；想用更简单的方法利用眼前的敌人；最初是用舌头缠住，最后是吸入/吐出；企划时耀西还没登场；能飞：体力制游戏掉坑即死太重；保持一次失误，但飞行可越过；敌人也能越过，GB 画面窄，简单点也好；刻意面向初学者，开发中多次被质疑；FC 末期作品普遍很难，ROM 容量小；不能放任不讲理的难度，否则新手进不来；卡比的角色：把初学者带进游戏世界；街机通关后也会反复玩；一开始就有声音测试，音乐很讲究；系列销量第一

#2 《星之卡比 梦之泉物语》
系列第 2 作，首次有复制能力；初代完成时 HAL 申请和议，濒临破产；设备被贴上查封条；公司指示：在 FC 上做卡比，大概设想 GB 直接移植；1992 年企划，SFC 已发售一段时间；不用 SFC：想快做快卖，SFC 准备环境就费时；判断：初学者向概念在成熟的 FC 市场行不通；课题：同时满足初学者与高手；答案：复制能力，更进一步利用敌人；初学者只用吸入吐出也能通关；熟练者用复制能力玩得更广；复制能力爆发性提升卡比的角色魅力；每个敌人都有了意义；制作辛苦，但做得到；GB 与 FC 像素数不同，卡比相对变小；画面宽，飞行过强；曾考虑去掉飞行，最终保留；对策：加大底部信息栏、中 Boss 锁卷轴、飞行变慢；单键小游戏作为给新手的服务；入口放在世界地图，可跳过；复制能力对后来的人气贡献巨大

#3 《星之卡比 超级豪华版》
1996 年 SFC 发售；两大概念：二人同时游玩、合集；宫本茂提议：卡比来做双人吧；横版跳跃游戏中双人很难：互相拉扯卷轴；Helper 系统：分为主角与配角；镜头只追主角，配角出画用「空间跳跃」回来；主角/配角与复制能力结合：敌人变成玩家角色；几乎每种复制能力都要做角色参数，非常辛苦；首次出现复制帽子，角色性大增；复制能力加入多种指令技；普通杂兵也有耐久力，招式强弱有了意义；卡比体力由 6 格变为模拟量；合集：剧本贴在软木板上，各自主题不同；理由：通关过长的游戏已经吃不消；首个剧本「春风」原本不能用复制，应制作人要求才加入；被砍掉的剧本「阳炎馆」；CG 背景与卡比相性不佳，但研究会通往下一作；樱井亲自导演的横版卡比只有 3 作

#6 《卡比的空中骑士》
2001 年卡比动画开播，樱井任系列统括导演；需要配合动画的游戏阵容；赛车游戏比正统动作更快完成；正统系列另有《梦之泉 DX》《镜之大迷宫》、NGC 版（后中止）；假设：漂移很好玩；漂移的快感来自风险与回报：失控、眼前是墙；刹车开始漂移时蓄力，「吸住再放开」；不做「追求顶点」的游戏，往拓宽方向设计；城市试炼：箱庭自由跑、不确定的强化与竞技场；清单检查器：早于 PS3/Xbox 的成就系统；与 N64 版《Air Ride》（雪板风格）无关；统括时尽量放手，但 Air Ride 几乎全部亲自看；交给别人一年多，连一台 Warp Star 都动不好；应主程序员要求回任导演，全面重做；3 个半月完成（素材已有不少）；机体看似个性迥异，其实同一规格；仅星型/机车型之分，其余都是参数差异；参数全由樱井亲自写；完成后离开 HAL，成为自由人

大乱斗系列

#4 《任天堂明星大乱斗》（初代）
1996 年进入 N64 时代，樱井独自学 3D（SGI + Softimage）；两个企划：无体力条的四人对战格斗、监视摄像头遥控机器人冒险；原型「格斗游戏龙王」：樱井负责企划/美术/模型/动作，岩田聪负责程序；规则已与大乱斗几乎一样；公司内多款作品未发售，急需尽快完成；遥控冒险认真做要两年，选了更快的四人格斗；不是否定格斗游戏；问题：连招里没有对手技术的介入；新手只能挨打旁观；累积伤害：对手每次反应不同，飞出画面就输；当时指令输入过度复杂；方向+按键，简单直觉；「弹摇杆」：利用输入完成所需的时间；任天堂角色不在原始企划书里，是后来谈下来的；家用格斗的难点：一开始就有一堆陌生主角；完成后营业/批发商反感「任天堂角色互殴」；发售后口碑慢慢扩散；首次起用声优，卡比的官方声音在此决定；规则可自由设定：好好玩想玩的部分

#5 《任天堂明星大乱斗 DX》
樱井的企划多为逻辑型：有课题再解决；DX 概念极简：让大乱斗飞跃式强化；斗士/舞台/画面/特效/动作/声音/体量/手感/道具/附加全部升级；N64 初代：每名斗士约 300 多边形，3 人以上约 200；贴图 64×64 或 32×32；萨姆斯的腿都是三角形；NGC 性能大增，也更好开发；首次光盘开发：流媒体播放实录音乐；管弦乐编曲，后来引出 PRESS START 演奏会与众作曲家合作；首次导入 CG 影片，过年不休画分镜；手办：游戏内角色有限，用收藏和解说回馈任天堂历史；Creatures 等团队外协助；作品需要「别处没有」的特点；全力发挥最大特点；NGC 上销量第一的软件

#9 《任天堂明星大乱斗 X》
2005 年 E3 公布 Wii 次日，岩田社长亲自邀约；若樱井不接，可能 DX 直接移植到 Wii；两大概念：联机对应、单人模式；Wii 标配联机，对应是必须；大乱斗与联机相性不好：在小圈子里称王才是乐趣；必须完全同步通信，比非同步的马车不利；只能匹配附近的人，延迟导致卡顿；技术问题不是他该想的：课题就要做；「亚空的使者」：影片、地图、贴纸强化、结局；想让每个角色都有见せ場；找不到合适外包，影片以外全部内制；团队首次超过 100 人；亚空模式参数另设，调整量翻倍；最终必杀：强调角色性；援助手办：让更多任天堂角色登场；我的音乐：一个世界不只一首曲；第三方参战：斯内克、索尼克；对樱井来说任天堂也是「外部公司」；DX 太快、对休闲层过难；Wii 面向休闲层，联机也承受不了高操作密度；放慢速度、偏休闲调整；首次引入测试员（仅 4 人）；不算 3DS/Wii U 合计时销量第二的大乱斗；若没有 X，系列可能就此终结

#11 《任天堂明星大乱斗 for 3DS / Wii U》
2011 年 E3 宣布双平台，正值《新光神话》冲刺；3DS：首个随身大乱斗，但性能难以支撑；Wii U：HD 但只是拼性能，难以跳出延长线；任天堂主机直到 Wii U 才支持 HD；连接「个人持有的掌机」与「聚会的主机」的优点；共享系统/动作/平衡，不会正好两倍工作量；能做的事受 3DS 性能牵制：冰山攀爬者做不了、击飞速度放慢；2012 年 6 月公布由 BNS 开发（樱井在 BNS 晃来晃去会引发猜测）；速度介于 X 与 DX 之间；3DS 与 Wii U 舞台分别制作，题材分别来自掌机/主机作品；3DS 独有「大乱斗冒险（Smash Run）」：5 分钟强化 + 最终对决，来自 Air Ride 城市试炼；Wii U 独有「大乱斗巡游（Smash Tour）」：大富翁式派对；可变强度：角色自定义、3 选 1 必杀技、Mii 斗士；amiibo：大乱斗周边原本禁止，amiibo 是例外；可培养 CP；可变强度不适合公平对战，却适合派对；首次由樱井以外的人设定参数（数名企划）；测试员大幅增加；3DS 四人对战 + 裸眼 3D + 60fps；首次支持在线更新，DLC 斗士；参战影片从此成为娱乐化发表形式；2014 秋冬发售，开发持续到 2016 年春

#12 《任天堂明星大乱斗 特别版》
Switch 未公布时就接到委托，是岩田先生给的最后任务；概念：全员参战；以往每作团队/公司/平台不同，几乎全部重做；4 代与特别版同在 BNS，人员和环境可沿用；Wii U 与 Switch 架构有些相似；未在 4 代登场的过去斗士只有 7 名；新作通常有斗士被舍弃；若有可能全员参战，只有现在；企划书在 4 代最后直播当天完成，完全无缝；为不让团队空档，企划者要最先行动；企划书 200 多页，也有被砍的（如 VR 对应）；参考斗士投票（有效票约 180 万）；每名斗士列出 70~100 项调整；节奏比 4 代更快，但比 DX 收敛；节奏变了参数就不能共用；舞台融合 3DS/Wii U，含战场化、终点化共 300 种；卡带约 16GB，Wii U 光盘 25GB，容量减半；音乐靠压缩技术缩到 4 代的 1/4；单人模式受限：亚空级别、自定义、手办都做不了；命魂：代替手办，「借力」+ 重现原作的战斗 + 可培养；灯火之星：横跨命魂战的模式；2018 年 3 月首次公布、6 月宣布全员参战、12 月发售；DLC 持续 3 年，与本体开发相当；疫情中迅速转为远程，保密与测试对战都更难；恐龙般巨大化的大乱斗不可能继续扩大路线

#7 《Meteos》

特别联动

#1 特别联动 #1：「太空侵略者之后的十年」（1978–1982）
与 GameCenter CX 有野晋哉课长联动；以往只能在任天堂节目里讲任天堂的事，YouTube 上可以自由做；开场话题：3D 晕眩——看远处、看自己要去的方向；樱井的「不满」：GameCenter CX 几乎不玩街机；讲游戏史离不开街机；企划：1978–1987 年 25 款街机连战；规则：有野玩到 Game Over，樱井一命即止；任一方失误就进下一作；《太空侵略者》(1978)：一列一列打，敌人越少移动越快；UFO 300 分要数射击次数；《小蜜蜂》(1979)：彩色、流畅、敌人模拟般运动；《爆破彗星》(1979)：海外的矢量扫描，线框画面；《吃豆人》(1980)：一次能量豆吃多只怪物得分高；《疯狂攀登者》(1980)：双摇杆攀爬，被花盆砸时下压摇杆；《Scramble》(1981)：横版卷轴、射击与炸弹两键、燃料；《大金刚》(1981)：讲跳跃动作游戏史必提；《挖金子》(1982)：用岩石压敌人更好；《月球巡逻》(1982)：多重卷轴、控制前后速度；和懂行的人一起玩能听到很多事

#2 特别联动 #2：「太空侵略者之后的十年」（1982–1985）
开场：有野被 NHK 认定为「游戏实况的鼻祖」；《Front Line》(1982)：敌弹射程与自机相同，FC 版更有名；《铁板阵》(1983)：用灰阶绘制、渐变兼作抗锯齿，画面远超当时水准；《铁板阵》有背景故事，敌人都有名字；动态难度：打掉雷达后敌人表回退、变简单；《马力欧兄弟》(1983)：同时双人，可合作也可互害；《Major Havoc》(1983)：矢量扫描，像《贝之冒险》的原型；海外仍偏线条写实，日本则彩色可爱；《空手道》(1984)：左摇杆移动、右摇杆攻击，招式要推到底；《Pac-Land》(1984)：早于《超级马力欧》的横版冒险，多重卷轴；原版用按键左右跑，此次改成方向键；《星际力量》(1984)：5 帧的漂亮爆炸；樱井换了低延迟显示器：后处理越多延迟越大；《宇宙巡航机》(1985)：画面、声音、强化系统都完美；FC 版发售时出现 MegaROM；强力强化的游戏一死就难以挽回；游戏越复杂，单局时间越长，街机收益可能下降；《魔界村》(1985)：有野主场，红色阿里马要等它落地再打

#3 特别联动 #3：「太空侵略者之后的十年」（1985–1987）
开场：有野想起未发售的 PS2 游戏《电线》；有野最难忘的挑战：《忍者龙剑传》；《太空哈利》(1985)：惊人的画面与速度感，体感框体；当时很多店提供「延长时间」：期间怎么死都不算；奖励关骑白龙撞障碍物；《梦幻空间》(1986)：横版射击 + 购物，画面风格独特；推荐买 Big Wing 与 Twin Bomb；《热血硬派》(1986)：GameCenter CX 常玩的国雄系列初代，偏写实；骑乘拳；《源平讨魔传》(1986)：据说取材于人偶净琉璃，有时出现冷笑话；樱井调到最高难度、最少蜡烛（体力）；《达拉斯》(1987)：三屏框体、座椅带扬声器，Boss 以水生生物为原型；双人一起玩会互相妨碍，强化给一个人更好；《魂斗罗》(1987)：双人合作，纵向画面关卡；《街头霸王》(1987)：压感按键越用力越强；初代波动拳一发约四成血，但很难出；回顾：变成彩色后一下子剧变，一年就完全不同；加演《拳无虚发》(1984)：大角色缩放的冲击，FC 只能把主角做小
