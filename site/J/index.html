    易懂与风格

    Clarity vs. Style

    UI 分类开篇：UI 指菜单、画面数字等显示类（手柄也算，但先不谈）。易懂的 UI 与风格化的 UI 也许是对立的。最好懂的例子是《女神异闻录》系列：风格首屈一指，但难说整齐、一眼难懂；可《P5》若用规矩的菜单就太无趣。UI 是抽屉，装什么因游戏而异——不能简单说易懂即好，要合目的。无论哪种，视线诱导、大小、窗口关联、亮度饱和度、字体都要下功夫。

  • #23:00

    文字大小

    Text Size

    用日语玩海外游戏时常觉得字太小。合适的字号因语言而异：汉字占空间大，日语一字信息多、句子短；英文字母简单、小也能认，但句子长；法语更长。只按英语布局、不灵活的画面会让字太小。如今问题减少：分辨率提高，也有可选字号的作品。Switch 等以掌机为前提的作品字较大，但字太大会减少酷感。红白机也用 8×8 点写汉字，靠大脑补全。

  • #311:21

    现代的便利功能（设置项）

    Modern Quality of Life Features

    大作就该把设置做得周到——这点现在看《最后生还者 Part I》（PS5）的设置就够了。以实况风格逐项浏览：无障碍（HUD 大小、色盲模式、高对比、放大镜、晕动对策、导航提示、读屏与音频提示、战斗无障碍与锁定解锁），以及操控自定义（命名方案、横握/倒握、摇杆互换、长按切换）、DualSense、字幕、画面、音频。键位不可改的时代有其价值，但如今玩家多样，按喜好调整是必要的。

  • #42:27

    读盘画面

    Loading Screens

    游戏一定会有数据读取，只是让人等着显示「Loading」不受欢迎。初代《生化危机》开门演出其实在后台读取——必要的读取时间与必然的演出完美配合（还能凭时长猜有没有僵尸）。但那是几十年前；现在讲求速度，单纯等待不受欢迎，至少显示在读取会让人接受。开发中与完成时读取时间不同，别依赖演出；用简洁、不土气、随处可显示的标志，并借它营造游戏世界氛围。

  • #52:39

    文字的强调

    Emphasizing Text

    以读文本为主的作品，常能控制文字：改大小、颜色、加动画、换字体（画面震动、闪烁也相近）。文字演出未必合严肃作品，但能更好传达角色情感、给无机的展开添色。系统上要能设置，并让翻译者直接调整脚本——各语言合适的强调方法不同：日本漫画文化的「书写文字」「漫符」等表现丰富。最好由各国母语者连演出一起考虑。

  • #62:01

    菜单决定世界观

    Menus Define Your World

    即使游戏性和内容相同，单凭 UI 和字体的用法就能改变目标人群。同样功能的选项画面，可以酷（大人也能玩）、可爱、恐怖、明亮华丽、电脑世界、和风、西洋、中华、亚洲……比起设计角色和背景，只换字体就能构成世界观，算轻松（虽然有时要从零做字体）。背景、框、图标也要配套；在保持易读的同时积极设计。字体与 UI 是为世界「打包」。

  • #72:27

    给游戏做色彩分区

    Color-Coding Your Game

    樱井导演的作品常按颜色区分菜单：《特别版》顶层分几种颜色，「大乱斗」进去后都以红为基调，「命魂」以绿为基调。但色彩分区未必总是好事：涂满颜色会显得低龄。合游戏的调性即可。任何游戏都推荐：同一画面不要混杂颜色。《3DS/Wii U》菜单有大幅角色画却不显乱，反而让图像印在脑中：找图比读字快得多（右脑 vs 左脑）。最终菜单要优先游戏的调性。

  • #82:17

    重要的东西就做大

    Make Important Elements Bigger

    樱井执导的菜单 UI 最与众不同之处：按重要度改变图标大小。从《Meteos》起，他多把菜单图标化并区分大小——越大越常用、越优先，以此引导玩家。GameCube 手柄的大 A 键也是类似思想。但这会损失通用性，翻译成长语言时也容易放不下文字。

  • #92:49

    我想快点选！

    I Want to Choose Fast!

    从 GameCube 开发、企划《大乱斗 DX》时起，樱井就多次向任天堂提议在手柄上加一个「滚轮」（旧称飞梭/jog dial）：让菜单和各种「从一堆东西里挑一个」的操作瞬间完成。本集真正想说的，是重新审视那些已经习以为常的菜单操作手感。

  • #102:22

    让玩家跳过，让玩家暂停

    Let Them Skip, Let Them Pause

    公司标志、开场动画、过场、演出……游戏中「玩家没在玩」的时刻，一定要能跳过，可能的话最好一次全部跳过。过场动画还必须能暂停。

  • #113:20

    按键设置

    Button Settings

    再简单的游戏也应能自定义按键（键位设置）。《大乱斗》需要支持多种手柄、方便客人设置，樱井介绍了他做键位画面时注意的几点：图形化手柄、先选按钮再按键、允许重复、绑定到名字，以及 PS5/Switch 确认键差异带来的问题。

  • #122:59

    推进文字

    Advancing Text

    人读画面文字和字幕通常很快，能「唰唰」地推进文字很舒服。精细演出的过场却很难按自己的速度推进。樱井作为玩家，希望这类场景能尽量快进：逐句跳过台词、或边玩边听对话——尽量让对话可跳，或许能让很多玩家开心。

  • #132:32

    给菜单加上说明文字

    Adding Help Text to Menus

    菜单项多用一个词表示，光看词常常不懂它是做什么的。这时画面下方的「帮助文字」很有用，应积极加入。最重要的规则：绝不用和菜单相同的词来说明；还要反复嚼碎、避免专业术语。

  • #142:34

    不靠文字也能明白

    Making Things Clear, Even Without Words

    虽然有极限，樱井的游戏尽量做到「看不懂语言也能玩」：图标放入画面和角色、频道中尽量用英文画面，并让连按确认键就能进入基本的主游戏。

  • #153:24

    HUD（抬头显示）

    HUDs

    叠在游戏画面上的信息叫 HUD。日本作品信息往往较多，海外作品偏克制、重沉浸。樱井举了《大乱斗》《卡比赛车》《Meteos》中的 HUD 小巧思：斗士头像、滚动背景、重叠半透明、1P 光标随距离隐现、坏掉的仪表、击败对手图标等。
