tldr: <b>UI 是用户界面</b>的意思，在游戏中指<b>菜单</b>、画面上出现的<b>数字</b>等显示类的东西。其实手柄也可说是 UI 的一部分，但先放一边，这个 UI 分类讲画面显示上的 UI 制作。说实话，<b>易懂的 UI 与风格性高的 UI，也许可以说是相反的东西</b>——不，「风格高」这个词本身就因人的价值观而异，不能一概而论。还是最好懂的例子是<b>《女神异闻录》系列</b>吧：非常时尚的 UI 构成，作为时尚 UI，他认为是<b>遥遥领先的第一</b>作品。但说实话很难说整齐，一眼难懂，可能还会让人头晕。UI 可以说是<b>抽屉</b>，抽屉当然越好懂越整齐越好；但因为方便就让《P5》用规矩的菜单构成，那就太讨厌了吧？依游戏，装进抽屉的东西的多少差别很大。也就是说，<b>不能断言单纯好懂就是好 UI、难懂就是坏 UI</b>，要在各个游戏中<b>配合目的</b>。他的作品服务太多，抽屉和装的东西太多，UI 也苦战；建造类作品在庞大的行李整理上也会迷惑——这也是 UI。想来《我的世界》中很多人建仓库，这近乎自己建文件夹的行为。但即便如此，各个菜单仍有应下功夫的地方：<b>视线诱导、显示要素的大小、用窗口化建立关联、亮度和饱和度、选择合适的字体</b>等。便利性与风格各有应优先的地方，但没有正解，所以要按照游戏的内容和世界来设计；在此之上能更亲切的话就没话说了。
