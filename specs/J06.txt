title: 菜单决定世界观
summary: 即使游戏性和内容相同，单凭 UI 和字体的用法就能改变目标人群。同样功能的选项画面，可以酷（大人也能玩）、可爱、恐怖、明亮华丽、电脑世界、和风、西洋、中华、亚洲……比起设计角色和背景，只换字体就能构成世界观，算轻松（虽然有时要从零做字体）。背景、框、图标也要配套；在保持易读的同时积极设计。字体与 UI 是为世界「打包」。
group: UI 基础
kp: 同一游戏性 + 内容，UI 与字体能改变目标人群 | 酷 → 大人也能玩 | 可爱、恐怖、明亮华丽 | 电脑世界、和风、西洋风、中华风、亚洲风 | 只换字体就能构成世界观：相对轻松 | 但有时要从零做字体，未必轻松 | 实际还要配合背景、框、图标 | 塑造世界氛围的效果巨大 | 保持易读的同时积极设计 | 字体与 UI 是构建世界的一部分 | 近乎为世界打包 | 颜色与装饰也重要 | 当下偏好简洁，但也要关注字体
tldr: 即使是相同的游戏性、相同的内容，<b>单凭 UI 和字体的用法，就能改变目标人群</b>。例如表示相同功能的选项画面：做得<b>酷</b>，看起来大人也能玩；也可以演出<b>可爱系</b>；或像<b>恐怖片</b>；<b>明亮华丽</b>的感觉；像<b>电脑世界</b>；<b>和风、西洋风、中华风、亚洲风</b>……与设计角色和背景相比，<b>单纯换字体就能连接到世界观的构成</b>，那就轻松了——不过有时也会<b>从零开始做整套字体</b>，所以也难说很轻松。实际上不只是字体，<b>背景、窗框、图标</b>等也要成套考虑；即便如此，塑造世界氛围的<b>效果绝大</b>，所以应该<b>在维持易读的同时积极设计</b>。字体和 UI 都是<b>构建那个世界</b>的东西——不，更近于<b>为世界打包</b>吧。不只是字体，其<b>颜色和装饰</b>也很重要。现在整体给人偏爱简洁的时代印象，但也要关注字体。
